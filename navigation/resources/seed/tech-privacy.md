## Security Tools & Databases

- **Exploit Database**: Archive of public exploits and corresponding vulnerable software
  - https://www.exploit-db.com/
- **Have I Been Pwned**: A database of known data breaches, allowing users to check if their credentials have been exposed
  - https://haveibeenpwned.com/
- **How Secure Is My Password?**: Check how secure your password is
  - https://www.security.org/how-secure-is-my-password/
- **MD5Hashing.net**: Everything on hashing
  - https://md5hashing.net/
- **MITRE ATT&CK**: Globally accessible knowledge base of adversary tactics and techniques
  - https://attack.mitre.org/
- **NIST National Vulnerability Database**: National Vulnerability Database
  - https://nvd.nist.gov/
- **VirusTotal**: Check whether a file or website is malicious
  - https://www.virustotal.com/gui/home/upload
- **web-check**: Tool for checking technical and security details of any website
  - https://web-check.xyz/

## Privacy Guides

- **Defensive Computing Checklist**: A list of internet-related things to be aware of and defensive steps to take in response to said things
  - https://defensivecomputingchecklist.com/
- **Dig Deeper**: Articles on privacy, software and related topics
  - https://digdeeper.neocities.org/index.xhtml
- **The Hitchhiker's Guide to Online Anonymity (Anonymous Planet)**: Detailed guide to protecting digital privacy and anonymity
  - https://anonymousplanet.org/guide/
- **The Information Hiding Homepage**: Digital watermarking and steganography
  - https://www.petitcolas.net/steganography/
- **IntelTechniques Workbook**: Workbook for finding and managing public data about yourself (OSINT)
  - https://inteltechniques.com/workbook.html
- **PRISM Break**: Opt out of global data surveillance programs like PRISM
  - https://prism-break.org/en/
- **PrivacyTools.io**: Privacy tools guide and encrypted software and services
  - https://www.privacytools.io/
- **Surveillance Self-Defense (EFF)**: Tips, tools and how-tos for safer online communications
  - https://ssd.eff.org/
- **Why to VPN**: How and why to route all your traffic through a VPN
  - https://digdeeper.neocities.org/articles/vpn.xhtml

## Privacy & Anonymity Tools

- **Free Proxies**: Guide to using free proxies
  - https://her.st/usr/bin/unlimited-free-proxies.html
- **Hyphanet (Freenet)**: Decentralized, censorship-resistant network (formerly Freenet)
  - https://www.hyphanet.org/index.html
- **I2P**: Invisible Internet Project
  - https://geti2p.net/en/
- **JustDeleteMe**: A directory of direct links to delete your account from web services
  - https://backgroundchecks.org/justdeleteme/
- **LogMeIn Hamachi**: VPN software
  - https://secure.logmein.com/products/hamachi/
- **OpenPuff**: Steganography Tool
  - https://embeddedsw.net/OpenPuff_Steganography_Home.html
- **SpywareBlaster**: Pre-emptive blocking of dangerous sites
  - http://www.brightfort.com/spywareblaster.html
- **SpywareWatchdog**: Tool for users to be aware of spyware
  - https://spyware.neocities.org/
- **Tor Project**: Free anonymizing proxy network with SOCKS interface
  - https://torproject.org/
- **ZeroNet**: Open, free and uncensorable websites using Bitcoin cryptography
  - https://zeronet.io/
