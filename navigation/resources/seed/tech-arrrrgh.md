# Privacy

- **Exploit Database**: Archive of public exploits and corresponding vulnerable software

- **Have I Been Pwned**: A database of known data breaches, allowing users to check if their credentials have been exposed
  - https://haveibeenpwned.com/
- **How Secure Is My Password?**: Check how secure your password is
  - https://www.security.org/how-secure-is-my-password/
- **MD5Hashing.net**: Everything on hashing
  - https://md5hashing.net/
- **MITRE ATT&CK**: Globally accessible knowledge base of adversary tactics and techniques
  - https://attack.mitre.org/

- **VirusTotal**: Check whether a file or website is malicious
